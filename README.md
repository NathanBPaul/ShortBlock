# Shorts Scroll Guard
Spent too much time scrolling through Shorts until it got exhausting, so I built this to combat that. There are much better videos to waste time on than an endless stream of Shorts.

## Features
- Open and watch a short as ususal.
- Detect a plea for dopamine by attempting to advance to the next one.
- Redirects the vary user to YouTube homepage.
- Display a full-screen ten second cooldown to discourage further short actions.
- Added option to block off shorts completely

## Tech stack
Had to use the following stuff:
- JavaScript for logic
- CSS for the blocking thingi
- Chrome Extensions Manifest V3 is the framework used.

## Local installation
1. Clone or download this repository.
2. Open chrome://extensions in Chrome.
3. Enable Developer mode.
4. Click Load unpacked.
5. Select the repository folder.

## Privacy
No care given to what you watch. Care given only to whether you choose to waste time on shortform videos or tradition long form videos. No data collected or anthing, just state that watches if you swipe down and then reminds you not to do that.
No accounts. No tracking. Just a little intervention between you and the next Short.
